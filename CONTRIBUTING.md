# Правила совместной работы

1. Не коммитьте напрямую в `main`, если команда использует Pull Request.
2. Для задачи создавайте ветку, например `feature/catalog-search` или `docs/readme`.
3. Делайте небольшие коммиты с понятными сообщениями.
4. Перед Pull Request проверьте локальный запуск и `npm run build`.
5. Не загружайте `.env`, пароли, токены, `node_modules` и личные данные.
6. Не добавляйте непроверенные сведения о сертификации товаров.
