# FORMA — учебный интернет-магазин спортивного питания

Адаптивный демонстрационный e-commerce проект для дисциплины «Стандартизация, сертификация и техническое документоведение».

> ⚠️ Все бренды, товары, характеристики, цены, рейтинги и отзывы вымышлены и нужны только для демонстрации. В проекте нет реальной оплаты, доставки и серверной авторизации. Не вводите настоящие пароли и персональные данные.

## О проекте

Основной интерфейс — интерактивная витрина **FORMA**, состоящая из трёх статических файлов:

| Файл | Назначение |
| --- | --- |
| `public/forma.html` | разметка |
| `public/forma.css` | стили и адаптивная вёрстка |
| `public/forma.js` | логика, каталог товаров (массив `R`), маршрутизация |

Витрина доступна по адресу `/forma.html`. Главный маршрут Next.js-приложения (`/`) автоматически перенаправляет на неё, поэтому все страницы работают с одного URL на hash-маршрутизации.

Исходная реализация на Next.js / React (интерфейс **FORGE**) сохранена в `src/` как основа для будущей покомпонентной миграции.

## Возможности

- каталог из 31 демонстрационного товара в 9 категориях (протеин, гейнеры, креатин, аминокислоты, витамины и минералы, предтренировочные, электролиты, батончики, аксессуары);
- поиск с подсказками по названию, бренду, категории и вкусу;
- фильтры: категория, бренд, цена, рейтинг (любой / 4.0+ / 4.5+), наличие, скидка, содержание белка;
- сортировка: по популярности, рейтингу, цене (по возрастанию и убыванию), скидке и новизне;
- карточки товаров с характеристиками, описанием и демонстрационными отзывами;
- избранное и сравнение товаров с сохранением в браузере;
- корзина с изменением количества, автопересчётом суммы и промокодом;
- тестовое оформление заказа и страница подтверждения;
- демонстрационные регистрация, вход, восстановление пароля, личный кабинет;
- панель управления товарами (добавление, редактирование, скрытие, удаление);
- светлая и тёмная тема;
- адаптивная вёрстка с нижней навигацией на мобильных устройствах;
- пустые состояния для корзины, избранного и поиска без результатов.

## Технологии

- HTML, CSS и JavaScript без сборки — витрина FORMA;
- Next.js 15 (App Router), React 19, TypeScript — основа проекта и перенаправление на витрину;
- Lucide React — иконки в Next.js-версии;
- `localStorage` — хранение данных демонстрационного аккаунта и пользовательских настроек;
- ESLint — проверка кода.

## Быстрый старт

### Требования

- Node.js LTS
- npm
- Git (для публикации на GitHub)

### Запуск для разработки

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000> — вы попадёте на витрину FORMA. Витрину можно открыть и напрямую: <http://localhost:3000/forma.html>.

### Проверка production-сборки

```bash
npm run build
npm start
```

### Проверка кода

```bash
npm run lint
```

> Для просмотра одной лишь витрины сборка не нужна: файлы `public/forma.*` можно открыть через любой статический сервер.

## Демонстрационные данные

| Что | Значение |
| --- | --- |
| Тестовый аккаунт | `demo@forma.test` / `demo123` |
| Промокод | `FIT10` — скидка 10 % |
| Доставка | бесплатно при сумме заказа свыше 5 000 ₽, иначе 350 ₽ |

Можно также создать собственный аккаунт через «Личный кабинет» → «Регистрация» — используйте вымышленные данные. Всё хранится только в `localStorage` текущего браузера и не синхронизируется между устройствами.

## Страницы витрины

Навигация построена на hash-маршрутах:

| Маршрут | Страница |
| --- | --- |
| `#/` | главная |
| `#/catalog` | каталог (поддерживает `?cat=<категория>`) |
| `#/product/<id>` | карточка товара |
| `#/favorites` | избранное |
| `#/compare` | сравнение товаров |
| `#/cart` | корзина |
| `#/checkout` | оформление заказа |
| `#/success/<id>` | подтверждение заказа |
| `#/login`, `#/register`, `#/forgot-password` | вход, регистрация, восстановление пароля |
| `#/account` | личный кабинет и история заказов |
| `#/admin` | управление товарами |

## Управление товарами

Страница `/forma.html#/admin` позволяет:

- добавить новый товар (`#/admin/new`);
- изменить описание и фотографии (`#/admin/edit/<id>`);
- скрыть товар из каталога и вернуть его обратно;
- удалить товар.

Изменения сохраняются в `localStorage` браузера (ключ `fm_products`). Исходный каталог хранится в массиве `R` файла `public/forma.js`, поэтому очистка данных браузера возвращает витрину к исходному состоянию.

### Ключи localStorage

Все ключи имеют префикс `fm_`: `fm_products`, `fm_cart`, `fm_fav`, `fm_cmp`, `fm_users`, `fm_me`, `fm_theme`, `fm_promo`.

```text
public/
  forma.html               # разметка витрины FORMA
  forma.css                # стили и адаптивность
  forma.js                 # логика, каталог, маршрутизация, админ-панель

  app/

    globals.css            # стили Next.js-версии
    layout.tsx             # корневой layout и metadata
  components/

  data/

docs/                      # проектная документация
test/                      # место для автоматических тестов
examples/                  # примеры карточек, JSON и скриншотов
.github/workflows/         # заготовка под GitHub Actions
```

## Публикация

1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. Войдите на <https://vercel.com/> через GitHub.
3. Нажмите **Add New → Project**, импортируйте репозиторий и нажмите **Deploy**.
4. После успешной сборки Vercel выдаст публичный HTTPS-адрес.

## Ограничения прототипа

Это учебный проект, а не production-система. Перед реальным запуском необходимо:

- подключить серверную базу данных и безопасную авторизацию;
- валидировать заказы на сервере;
- добавить реальные условия доставки и оплаты;
- заменить вымышленные данные проверенными сведениями о товарах и документах соответствия.

Не публикуйте вымышленные сертификаты, декларации или номера документов как настоящие. Информация о продуктах носит справочный характер и не является медицинской рекомендацией.

## Участие в разработке
